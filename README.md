

 App name & purpose

**Learning Journey** helps learners build a daily learning habit. Users set what they want to learn and for how long, then log each day as learned or freezed to keep their streak going.

## Main features

- Set a learning goal by choosing a topic and a duration (week, month, or year).
- Log today as learned to grow the streak.
- Freeze a day to keep the streak (2 freezes per week, 8 per month, 96 per year).
- See this week's days and the number of learned and freezed days.
- The streak resets after 32 hours without logging, or when the goal is updated.
- Update the learning goal, with a confirmation before the streak starts over.
- See whether the goal was reached when its duration ends, and set a new one.
- View all previous learned and freezed days in a calendar.
- Progress stays saved after closing the app.
